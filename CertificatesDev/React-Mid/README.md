# React Mid - Certificates.dev

Esta carpeta está destinada a almacenar los ejercicios, notas y proyectos prácticos correspondientes al nivel **Mid (React Developer)** de [Certificates.dev](https://certificates.dev/).

## Contenido y Objetivos
- Ejercicios prácticos del free weekend.
- Notas de estudio sobre conceptos intermedios/avanzados de React.
- Pruebas y simulacros de examen.

## Estructura sugerida
- `/ejercicios`: Ejercicios de código resueltos.
- `/notas`: Resúmenes y apuntes de conceptos clave.
