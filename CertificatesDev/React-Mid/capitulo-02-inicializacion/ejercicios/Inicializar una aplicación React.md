# Inicializar una aplicación React

## Descripción del desafío
En este reto de programación, crearás una nueva aplicación React utilizando Vite.

## Requisitos y Objetivos
- [ ] **Inicializar la aplicación:** Crea una nueva aplicación React utilizando Vite y la plantilla para React (`my-react-app`).
- [ ] **Navegar al proyecto:** Dirígete al directorio de tu nuevo proyecto desde la terminal.
- [ ] **Instalar dependencias:** Realiza la instalación de todos los paquetes iniciales necesarios.
- [ ] **Iniciar el servidor:** Levanta el servidor local de desarrollo.
- [ ] **Analizar estructura:** Observa la estructura del proyecto generada y analiza para qué sirve cada carpeta/archivo.
- [ ] **Velocidad de inicio:** Compara el tiempo de arranque frente a herramientas tradicionales.
- [ ] **Comprobar Fast Refresh:** Realiza un cambio en un componente, observa cómo se actualiza la interfaz y analiza por qué no se pierde el estado.
